HOW TO RUN THE APPLICATION
--------------------------

PREREQUISITES:
1. Java JDK 17 or higher installed
2. MySQL Server running (version 8.0+)
   - Database: cmpe343_project
   - User: myuser
   - Password: 1234
   (Database will be provided separately)

   NOTE: If you encounter an error while importing the database:
   1. In MySQL Workbench, go to 'File' -> 'Open SQL Script'.
   2. Select the provided SQL file.
   3. Locate and DELETE the line (usually around line 24) that says:
      SET @@GLOBAL.GTID_PURGED=/*!80000 '+'*/ '...';
   4. Execute the script to create the database.
   (If the import works without errors, skip this step.)


==============================================================
                    STEP-BY-STEP INSTRUCTIONS
==============================================================

STEP 1: CREATE OUTPUT FOLDER
-----------------------------
Open PowerShell in the project directory and run:

    mkdir out

STEP 2: COMPILE THE PROJECT
-----------------------------
Run this command to compile all source files:

    javac -d out --module-path lib -cp "lib/*" --add-modules javafx.controls,javafx.fxml,javafx.media -encoding UTF-8 src/com/greengrocer/*.java src/com/greengrocer/controllers/*.java src/com/greengrocer/dao/*.java src/com/greengrocer/models/*.java src/com/greengrocer/setup/*.java src/com/greengrocer/util/*.java

STEP 3: RUN THE APPLICATION
-----------------------------
Run this command to start the application:

    java --module-path lib --add-modules javafx.controls,javafx.fxml,javafx.media --enable-native-access=javafx.graphics "-Djava.library.path=lib" -cp "out;lib/*" com.greengrocer.Main

==============================================================
                    FEATURES BY USER ROLE
==============================================================

CUSTOMER:
- Browse products with search, filter by category, and sort options
- View product details, images, and prices
- Add products to cart (kg or piece based)
- Quantity validation (minimum 0.5 kg, stock check)
- View and manage shopping cart
- Apply discount coupons at checkout
- Use G-Points (loyalty points) for discounts
- Schedule delivery date and time (within 48 hours)
- View order summary before purchase
- Minimum cart value enforcement (₺20)
- PDF invoice generation and download
- View order history and track status
- Cancel orders within 30 minutes (if Pending)
- Rate and comment on carriers after delivery
- Add/remove products from favorites
- Update profile information
- Change password
- Send messages to store owner
- "Also Bought" product recommendations

CARRIER:
- View available orders waiting for pickup
- Take/select orders to deliver
- View order details (customer, address, products)
- Update delivery status (Picked Up → Delivering → Delivered)
- Cannot deliver before scheduled delivery time
- View completed deliveries
- View personal ratings and comments from customers
- See average rating score
- Communicate with store owner

OWNER:
- Add new products with images
- Edit product details (name, price, cost, stock, threshold)
- Delete products
- Set low stock threshold (price doubles when stock ≤ threshold)
- Employ new carriers
- Fire existing carriers
- View all orders and their status
- View and reply to customer messages
- Create and manage discount coupons
- Set loyalty program standards (G-Points)
- View carrier ratings and performance
- View reports and analytics:
  * Sales by category (pie chart)
  * Revenue trends (daily/weekly/monthly bar chart)
  * Profit/loss per product
  * Cost analysis
  * Total revenue, orders, and profit summaries
- View customer and carrier analytics
- Peak hours analysis
